# Тест-кейсы для системы управления вендинговыми автоматами

## TC-01: Авторизация пользователя
**Предусловие:** Пользователь существует в БД (email: alex.ivanov@example.com, пароль: password)
**Шаги:**
1. Открыть приложение
2. Ввести email: alex.ivanov@example.com
3. Ввести пароль: password
4. Нажать "Войти"
**Ожидаемый результат:** Успешная авторизация, отображение главной страницы, фото и ФИО пользователя в sidebar
**Приоритет:** Высокий

## TC-02: Хеширование пароля bcrypt
**Предусловие:** Новый пользователь регистрируется
**Шаги:**
1. Вызвать POST /auth/register с password: "test123"
2. Проверить поле PasswordHash в БД
**Ожидаемый результат:** Пароль хранится в виде bcrypt хеша (начинается с $2a$)
**Приоритет:** Высокий

## TC-03: Отображение бокового меню
**Предусловие:** Пользователь авторизован
**Шаги:**
1. Проверить пункты меню
**Ожидаемый результат:** Отображаются: Главная, Монитор ТА, Детальные отчеты, Учет ТМЦ, Администрирование ТА
**Приоритет:** Средний

## TC-04: Блок "Эффективность сети"
**Предусловие:** Пользователь на главной странице
**Шаги:**
1. Проверить наличие блока
2. Проверить значение процента
**Ожидаемый результат:** Отображается процент работающих автоматов, данные из API
**Приоритет:** Средний

## TC-05: Блок "Состояние сети"
**Предусловие:** Пользователь на главной странице
**Шаги:**
1. Проверить наличие круговой диаграммы

**Ожидаемый результат:** Зеленый - работает, красный - не работает, синий - на обслуживании

## TC-06: Монитор ТА - фильтры
**Предусловие:** Переход в раздел Монитор ТА
**Шаги:**
1. Выбрать фильтр "Работает"
2. Нажать "Применить"

**Приоритет:** Высокий

## TC-07: Монитор ТА - сортировка по статусу
**Предусловие:** Открыт Монитор ТА
**Шаги:**
1. Нажать "Сортировать по статусу"
**Ожидаемый результат:** ТА отсортированы по статусу алфавитно

## TC-08: Администрирование - удаление ТА
**Предусловие:** Пользователь в разделе Администрирование

1. Выбрать ТА из списка

3. Подтвердить удаление
